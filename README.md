# Maria Thurn – Portfolio

My personal portfolio website, showcasing my skills, projects and how to get in touch.

Built with **React**, **TypeScript** and **Vite**, styled with plain CSS.

## Features

- Single-page layout with About, Skills, Projects and Contact sections
- Sticky navbar that changes colour to match the section currently in view
- Responsive layout with a mobile menu
- Accessible markup: semantic headings, labelled navigation, keyboard focus styles and reduced-motion support

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run preview  # preview the production build
```

## Project structure

```
src/
  components/   # One component per section (Navbar, About, Skills, Projects, Contact)
  styles/       # Component styles + global.css with shared design tokens
  assets/       # Images, video, CV and thesis
```
